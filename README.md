# Rock Paper Scissors

A simple Rock Paper Scissors game built as part of the curriculum from The Odin Project.

## About

This project was built to practice using JavaScript to add interactivity to a webpage and manipulate the DOM.

The game allows the player to choose between Rock, Paper, and Scissors while the computer randomly selects its own move. The first player to reach 5 points wins the game.

## What I Practiced

- JavaScript functions and conditional logic
- DOM manipulation
- Event listeners and handling user interactions
- Updating webpage content dynamically
- Managing game state
- Basic CSS styling

## Built With

- HTML
- CSS
- JavaScript

## How to Play

1. Choose Rock, Paper, or Scissors.
2. The computer will randomly choose a move.
3. The winner of each round receives a point.
4. The first player to reach 5 points wins.
5. Click **Play Again** to start another game.
